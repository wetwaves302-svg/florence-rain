## 授權來源建議

- Wikimedia Commons（commons.wikimedia.org）：搜尋英文名稱，例如 Ponte Vecchio、Santa Croce Florence、Sagrada Familia interior columns。每張圖的頁面會標示授權（Public domain、CC BY、CC BY-SA）。
- 使用 CC BY 或 CC BY-SA 時，請在遊戲或講義中註明作者與授權，例如「Photo: 作者名, CC BY-SA 4.0, via Wikimedia Commons」。
- 大衛像本身是 1504 年的作品，屬公共領域；但「照片」有拍攝者的著作權，仍要看照片頁面的授權。
- 不要使用搜尋引擎圖片結果或旅遊網站的照片，授權不明。
- FINAL 的圖二、圖三要和題目的文字條件對得上：圖二必須是暖色（橙紅）光線，圖三必須看得到吊車，否則圖文互證的答案會失準。
